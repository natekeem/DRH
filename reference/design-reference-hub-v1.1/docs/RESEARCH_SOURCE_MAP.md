## Recommended License Metadata Additions
현재 기획의 metadata에 아래 필드를 추가하는 것을 권장한다. 실제 조사에서 README, 저장소 LICENSE, 사이트 이용약관, 개별 asset 권리가 서로 다른 사례가 반복적으로 확인되었기 때문이다.

```yaml
license_scope: [code, demo, screenshot, image, font, icon, brand]
license_evidence_url:
license_evidence_commit:
license_checked_at:
license_conflict: false
redistribution_mode: source_copy | runtime_dependency | link_only | attribution_required
preview_rights:
source_version:
source_commit:
```

## Ingestion Policy Suggested by the Research
1. **🟢도 무조건 미러링하지 않는다.** 원본 URL/GitHub/author/license evidence를 함께 저장한다.
2. **Screenshot 권리가 확인되지 않으면 외부 gallery screenshot을 자체 CDN에 복제하지 않는다.** 링크/원본 thumbnail 정책을 별도로 검토한다.
3. **Marketplace/aggregator는 discovery source로만 취급한다.** 실제 code ingest는 원 저작자 repository/license까지 역추적한다.
4. **LICENSE > 공식 Terms > README의 'free/open source' 문구 순으로 신뢰한다.** 충돌 시 `license_conflict: true`로 둔다.
5. **Brand-derived DESIGN.md는 코드 라이선스와 별개로 상표·trade dress·브랜드 자산 위험을 표시한다.**
