# DRH 5분 시작하기

## 1. Reference 선택

Explore에서 원하는 디자인을 고르고 Source와 복사 가능 범위를 확인하세요.

## 2. Preview 확인

Design DNA와 Component Library를 비교하고 Applied Canvas에서 적용 느낌을 확인하세요. 공식 제품 화면이 아닌 DRH 예시입니다. 버튼과 입력을 조작하고 모바일 크기도 확인합니다.

## 3. DESIGN.md 다운로드

Detail 맨 아래 **Continue in your project → Download DESIGN.md**로 저장하고 프로젝트 루트에 두세요. 문서가 없는 Reference는 Agent Package를 사용합니다.

## 4. Agent 적용

**Copy apply prompt**를 Coding Agent에게 전달하고 수정할 화면을 한 문장으로 덧붙이세요.

## 5. 결과 검수

색·글자·간격·모서리와 입력·클릭을 비교하세요. 390px / 1440px에서 잘림, 키보드 조작, reduced motion을 확인합니다. 대체 글꼴 표시와 출처·권리 고지를 유지하세요.

자세한 내용은 [Implementation guide](#/guides/apply-demo-code), [프로젝트 DESIGN.md 작성](#/guides/create-design-md), [라이선스 안내](#/guides/license-basics)에서 확인하세요.
