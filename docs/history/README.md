# 변경 이력과 검증 기록

여기에는 각 시점의 릴리스 노트, 검증 결과, 작업 인수인계가 있습니다.

- [감사 기록](audits/)에는 릴리스와 브랜드 작업별 검증 결과가 있습니다. 당시 스크린샷과 출력은 [artifacts](../../artifacts/)에 연결되어 있습니다.
- [변경 이력](changelog/)에는 초반 버전과 사용성 개선 내역이 있습니다.
- [기획](planning/)과 [인수인계](handoffs/)에는 당시 계획과 작업 맥락이 있습니다.

현재 저장소의 실행 방법과 계약은 [문서 안내](../README.md)에서 확인하세요.
